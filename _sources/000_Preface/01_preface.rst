Preface
=========================================


.. only:: html


    Spreadheet formulas (as used in MS Excel and LibreOffice Calc) are probably the most widely used programming language in the world. In addition to the built-in formulas, there is also the option to write user-defined functions (UDFs) in the Basic dialects of these programs.

    XlCalcNet extends these options by providing an additional set of functions which are accessible through the function dialog (MS Excel) or function wizard (LibreOffice Calc), and expect as first argument a string containing code written in Python. This code can call any function that is available in the underlying Python installation (currently supported are versions 3.8 - 3.14), which the user can freely populate with additional packages as needed.
