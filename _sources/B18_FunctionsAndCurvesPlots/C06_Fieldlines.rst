Field lines
==============================================================



Colored electric field lines: 1 positive vs 1 negative charge
------------------------------------------------------------------------------------------


The Python code for the example below can be found online in the ``DataXlCalcNet`` repository or in the corresponding local ``DataXlCalcNet`` folder in the file `D01_4_ColoredFieldLines.py <https://github.com/duhadler/DataXlCalcNet/blob/master/DataXlCalcNet/A01_ExamplesPython/B18_FunctionsAndCurvesPlots/C06_Fieldlines/D01_4_ColoredFieldLines.py>`__.

To produce the figure as shown below, the try-block at the end of the file should look like this:

.. code-block:: python

    try:
        if __name__ == '__main__':
            UseColors_ = True
            Model_ = 1  # 1, 2, 3, 4
            ColoredFieldLines(UseColors=UseColors_, Model=Model_)
